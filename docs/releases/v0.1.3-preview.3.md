# Exact rc1 compatibility candidate — 2026-11-04

The two 0.1.3-preview.3 candidate packages add only the exact official SDK
`0.2.2-rc.1` to their existing Host and three SDK peer declarations. Product
index, client, domain and service code remain unchanged from 0.1.3-preview.2.
The public 0.1.3-preview.2 packages and their release assets remain immutable.

Official Desktop mac-arm64 currently names `0.2.2-rc.1`; npm `latest` remains
`0.2.1-rc.5`, while npm `next` names `0.2.2-rc.1`. The gate now reads all three
independently and requires the Desktop version to match a reviewed exact SDK.
Missing/malformed evidence, a mismatched next version and an untested or alpha
Desktop fail closed. No alpha version is added to the supported set.
