# Workproof 0.1.2

作者：牛村木木山。

修复官方 DeepSeek Harness `0.2.1-rc.3` 下两插件因精确旧 peer 版本而无法启用的问题。
兼容范围限定为实测的 `0.2.0-rc.2` 与 `0.2.1-rc.3`，生产依赖 Zod 升至 `4.6.6`，
修复 GHSA-mrhx-c7xc-m3w5。没有新增业务功能，原工具、命令、存储格式和界面保持原实现。

正式仓库现为 [oxmumu3/dsh-workproof](https://github.com/oxmumu3/dsh-workproof)，
已完成实际仓库迁移，原历史与 v0.1.0 资产保留。

两个插件独立安装：

- `dsh-delivery-receipts-0.1.2.tgz`：交付回执。
- `dsh-evidence-ledger-0.1.2.tgz`：研究证据账本。

从本 Release 下载 `.tgz` 与 `SHA256SUMS`，在官方应用的插件管理器输入对应包地址
或已下载包的绝对路径。记录继续使用原存储格式；不要删除 Harness 数据目录。

最终包通过 63 项源码回归、12 项发行审计回归、旧 rc.2 的完整 4 项 Host 集成，
以及当前官方 rc.3 应用的隔离安装激活和完整 4 项工具/命令/持久化集成。
生产依赖审计为 0 漏洞。测试不使用真实项目、模型凭据或微信；不代表新版
界面或实际模型工作流已验收。详见 [验证记录](../verification.md)。
